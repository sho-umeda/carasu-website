  • 2026年は91.1%の企業が中途採用に積極的と回答しています。採用は完全に売り手市場です。

03

SNSと求人媒体は
「どちらが優れているか」ではなく役割が違う

求人媒体は「今すぐ転職したい顕在層」へ、
SNSは「まだ転職を考えていない潜在層」へ。
違うからこそ、組み合わせることで強くなります。

SNS潜在層×求人媒体顕在層

2つは同じ土俵に立っていない

ここが、この記事でいちばんお伝えしたい部分です。

求人媒体は「今すぐ転職したい顕在層」にアプローチします。
SNSは「まだ転職を考えていない潜在層」にアプローチします。

目的もユーザーの行動も異なるため、
二者択一で考えると、必ず片方の層を取りこぼします。

比較表：求人媒体とSNSの役割の違い

比較軸求人媒体SNS
届く相手顕在層（今すぐ転職したい）潜在層（まだ転職を考えていない）

採用ファネルで考えると分担が見える

採用は「知る → 興味を持つ → 応募する → 選考 → 入社」の流れで進みます。

  1. 01知るSNSが潜在層との最初の接点をつくる
  2. 02興味を持つSNSで人・文化・仕事のリアルを伝える
  3. 03応募する求人媒体・採用サイトで条件を確認する
  4. 04選考求人媒体・採用サイトが具体的な行動を支える
  5. 05入社発信と実態の一致が納得感につながる

違うから、組み合わせて強くなる。
これがSNSと求人媒体の関係です。

04

採用コストで比較するとどうなる？
求人媒体とSNSの費用対効果

求人媒体は採用ごとに発生する変動費です。
SNSは運用を続ける固定費ですが、
投稿が残り、中長期の採用資産になります。

費用だけでなく
何が残るかで比較する

それぞれの費用感

項目求人媒体SNS
費用の形掲載料・成功報酬（変動費）運用費・広告費（固定費）
目安転職サイトの採用単価は1人あたり平均37.0万円投稿自体は無料。広告運用は月30万〜50万円程度が目安
採用が終わると費用も露出も消えるコンテンツが資産として残る
向いている状況今すぐ1名決めたい継続的に母集団を作りたい

ここで誤解しやすい点

「SNSは無料だから安い」と考えるのは正確ではありません。
投稿を作る人の時間は、確実にコストです。

一方で、求人媒体の費用は、採用が終われば何も残りません。
SNSはコンテンツが蓄積されるため、
中長期的な視点で費用対効果を考えることが大切です。

判断の目安

  • 3か月以内に1名決めたい → 求人媒体に予算を寄せる
  • 来年以降も継続して採用する → SNSに時間を投資する価値がある
  • 両方ある → 求人媒体で今の枠を埋め、SNSで来年の母集団を作る
05

結局、SNSと求人媒体は
どう使い分けるべき？

短期の応募獲得は求人媒体、
将来に向けた採用ブランド形成はSNS。
採用時期と人数に合わせ、役割を分けて運用します。

いまの採用と
未来の採用をつなぐ

短期と長期で役割を分ける

短期の応募獲得には、求人媒体が有効です。
将来に向けた採用ブランド形成には、SNSが有効です。

業種・職種・採用人数・採用時期に応じて、
両方を役割分担させることが、これからの中途採用成功のカギとなります。

使い分けの具体例

状況推奨する組み合わせ
欠員補充・急ぎの1名求人媒体を主軸に。SNSは補助
毎年5名以上を継続採用SNSを主軸に。求人媒体は不足分の補填
専門職・母集団が小さい職種SNSで認知を作り、指名で来てもらう設計
多店舗・多拠点で通年採用SNSで全社の雰囲気を発信し、媒体は店舗別に出す

FAQ

よくある質問

Q1. SNS採用と求人媒体、どちらから始めるべきですか？

採用の緊急度で決まります。3か月以内に人が必要なら求人媒体です。SNSは投稿が蓄積されて効果が出るまでに数か月かかるため、急ぎの欠員補充には向きません。一方、来年以降も継続して採用する予定があるなら、いま並行してSNSを始める価値があります。求人媒体は掲載を止めた瞬間に露出がゼロになりますが、SNSの投稿はアカウントに残り続けるためです。

Q2. 求人媒体をやめてSNSだけにすることはできますか？

おすすめしません。SNSが届くのは「まだ転職を考えていない潜在層」で、「今すぐ転職したい顕在層」は求人媒体で探しているためです。SNSだけにすると、応募を決めた人が最後に条件を確認する場所がなくなります。SNSで興味を持った人の着地点として、求人媒体か自社の採用サイトのどちらかは必要です。

Q3. SNS採用の費用はどれくらいかかりますか？

投稿自体は無料で始められます。広告を出す場合は月30万〜50万円程度が目安です。ただし、実際のコストは投稿を作る社内の人件費が中心になります。転職サイトの採用単価は1人あたり平均37.0万円で、こちらは採用が終わると何も残りません。SNSはコンテンツが残るため、中長期の視点で比較してください。

Q4. 中途採用でもSNSは効果がありますか？ 新卒向けではないですか？

中途採用でも効果があります。国内のSNS利用者はLINEが約9,900万人、Xが約6,700万人、Instagramが約6,600万人、TikTokが約4,950万人で、いずれも数千万人規模です。採用ターゲットとなる20代・30代の多くが日常的に利用しており、「若者だけのメディア」という前提は実態と合っていません。

Q5. SNSと求人媒体の予算配分はどう決めればいいですか？

直近1年の採用経路ごとに、1人あたりの採用単価を計算することから始めてください。そのうえで「求人媒体を止めたら採用がゼロになるか」を確認します。ゼロになる場合は媒体依存の状態です。まず現在の媒体予算を維持したまま、SNSに月数万円規模から着手し、半年後に応募経路がどう変わったかで配分を見直す進め方が現実的です。
